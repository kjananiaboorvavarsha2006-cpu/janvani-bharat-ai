# System Design — JanVani Bharat

## Workflow

User Input (Voice/Text)
→ Speech-to-Text (if voice)
→ NLP Attribute Extraction
→ AI Eligibility Matcher
→ Scheme Knowledge Base
→ Recommendation Engine
→ Multilingual Response

## Core Components

Frontend: Chat-style web/mobile UI
Backend: API server
AI Layer: NLP extraction + semantic matching
Database: Structured scheme dataset

## Model Type

* Natural Language Processing
* Semantic Matching
* Recommendation Ranking

## Why This Is AI-Driven

The system interprets natural language, understands user context, and performs semantic eligibility matching — not fixed keyword filtering.

## Usability Features

* Simple chat interface
* Voice input support
* Local language responses
* Low-bandwidth mode

## AI-Assisted Development

Dataset structuring, prompt design, and prototype logic were built using AI-assisted development tools.
